
# Furkan Yıldırım Frontend

Frontend'i yayımladığım domain adresi : BURAYA VERCEL DOMAIN GELECEK

1) Üye Olma: /signup

2) Giriş Yapma: /login

3) Kitap Arama: /search

4) Kitap Detay Sayfası: /book/[id]

5) Kitap Puanlama: Kitap detay sayfasında puanlama bulunmaktadır.

6) Kitap İncelemesi Yazma: Kitap detay sayfasında inceleme yazma bulunmaktadır.

7) Profil Sayfası: /profile

8) Okuma Listesi Oluşturma: /profile/reading-list/new

9) Popüler Kitaplar Listesi: /popular

10) Profil Düzenleme ve Puan Düzenleme: 
    - Profil Düzenleme= /profile/edit
    - Puan   Düzenleme= profildeki puanlarım kısmında mevcut
